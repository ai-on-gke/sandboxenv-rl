open pull requests #209, #230, #235 and #242 read. Python paths are under

### Naming note: `exec` and `shell`

The Python direct path names its span `ate_env_client.shell` with a child `start_process`; the
Python fleet handle and the Go client name theirs `exec`.
[docs/observability.md](../../observability.md) documents `exec` and says a Go client's spans take
the place of the `ate_env_client.*` ones. Decision D6 in the README: Go keeps `exec` and adds the
`start_process` child. Renaming or aliasing the Python `shell` span is a Python follow-up.
