# Generated Python protobuf stubs

All files in `_gen/` (`*_pb2.py`, `*_pb2.pyi`, `*_pb2_grpc.py`) are generated code. Never hand-edit
these files.

To update Python stubs after modifying `proto/ateenv/v1alpha/*.proto`, run from repository root:

```bash
make python-protos
```

See [docs/dev/code-layout.md](../../../../../docs/dev/code-layout.md).
